# Links para compartir tu web (y saber de dónde llegan las consultas)

**Qué es esto:** el sitio es el mismo, pero cada link lleva una "etiqueta" al final.
Así podemos ver cuánta gente llega desde Instagram, Facebook o Google, y cuál canal trae más consultas.

**Qué tenés que hacer:** copiar cada link y pegarlo donde dice "Dónde ponerlo". Una sola vez.

| Facebook: sitio web del perfil o página | https://estudiojuridico-sanchez.com.ar/?utm_source=facebook&utm_medium=perfil |
| LinkedIn: sitio web del perfil | https://estudiojuridico-sanchez.com.ar/?utm_source=linkedin&utm_medium=perfil |

| Firma del mail | https://estudiojuridico-sanchez.com.ar/?utm_source=email&utm_medium=firma |

**Reglas simples**
- No cambies nada de lo que está después del `?`.
- Un link distinto por cada lugar. No uses el mismo en todos.
- Las visitas que ya existen no se pierden: siguen llegando, solo que ahora vamos a saber de dónde.
